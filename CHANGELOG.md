# Changelog

## 0.1.0

First release of Kartis, a Rust chart library for Glory.

- Shared chart scenes for SVG, browser Canvas, Glory widgets, and optional CPU raster rendering.
- Cartesian, radial, statistical, hierarchy, flow, geographic, and time-based chart layouts.
- Scales, axes, legends, annotations, typed interactions, viewport controls, and motion.
- Optional GeoJSON, time-zone, text shaping, and bidirectional raster text support.
- English and Simplified Chinese documentation and runnable examples.

This release does not include a GPU renderer. See the
[feature gap list](docs/feature-gaps.md) for remaining differences from D3 and Nivo.
