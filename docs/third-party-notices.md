# Third-party algorithm notices

## D3 continuous color transforms and piecewise scales

`src/color_scale/transform.rs` adapts `d3-scale` 4.0.2 `sequential.js`,
`diverging.js`, `log.js`, `pow.js` and `symlog.js`. The piecewise scale and
full-domain viewport integration follow its `continuous.js` polymap and
`d3-zoom` 3.0.0 `src/transform.js` rescaleX/rescaleY. Copyright 2010-2021
Mike Bostock; the ISC permission and disclaimer reproduced below apply.
Independent generators execute original package functions. Fixed cross-runtime
rounding differences remain separate from ordinary numeric equivalence.

## D3 fitted geographic inverse

`src/geo/inverse.rs` adapts the inverse equations and rotation conventions of
`d3-geo` 3.1.1 projection modules, including Equal Earth and Natural Earth
iteration. Copyright 2010-2024 Mike Bostock; the same ISC terms apply.
The development-only original d3-geo/d3-array bundle, unmodified segment
hashes and complete original notices are preserved with
`tests/fixtures/geo-inverse-d3-source.json` and
`tests/fixtures/geo-inverse-d3-LICENSE.txt`. Geographic exact-cap and singular
profiles are recorded separately from ordinary inverse comparisons.

## D3 conic projections and antimeridian rejoining

`src/geo/conic_kernel.rs`, `src/geo/conic.rs` and the Conic-specific
`src/geo/conic_seam.rs` adapt `d3-geo` 3.1.1's conic projection equations,
Albers intrinsic frame, and antimeridian clipping/rejoining algorithms.
Copyright 2010-2024 Mike Bostock; the complete ISC notice is preserved in
[`geo-inverse-d3-LICENSE.txt`](../tests/fixtures/geo-inverse-d3-LICENSE.txt).
Checked finite latitude, coefficient, inverse-conditioning and resource-budget
profiles are Kartis-specific admission rules.

The [portable reference producer](../tests/fixtures/geo-conic/producer.mjs)
checks original `d3-geo` 3.1.1 ESM modules against the pinned original UMD
bundle, using original `d3-array` 3.2.5 UMD exports as its ESM bridge.
It does not claim original `d3-array` ESM execution. Original source hashes,
fixtures and complete notices accompany the reference package.
The [unsafe-coefficient supplement](../tests/fixtures/geo-conic-unsafe/producer.mjs)
retains original multi-turn, radial-fold and incorrect inverse results as
diagnostic references. JavaScript reference code is development-only;
production layouts and rendering use Rust.

## D3 signed power scales

`src/scales/power.rs` and the shared axis/viewport integration follow
`d3-scale` 4.0.2 `pow.js`, `continuous.js` and `linear.js`. The implementation
uses signed powers, source-domain ticks/nice and the original bimap order.
Connected-branch and finite/invertible-transform checks are explicit Kartis
profiles. Independent fixtures execute the original package through
`scripts/power-scale-reference.mjs`; those JavaScript packages remain
development-only. The ISC copyright notices and terms below apply.

## D3 discrete color partitions

`src/color_scale.rs` follows `d3-scale` 4.0.2 `quantile.js` and
`threshold.js`, including right-bisect ownership and R7 quantile cuts from
`d3-array`. The finite-input, empty-source and finite legend-window profiles
are explicit Kartis extensions. Independent numeric fixtures are generated
by `scripts/discrete-color-reference.mjs`; its JavaScript packages remain
development-only. The ISC notices and terms reproduced below apply.

## D3 linear nice boundaries

The stable decimal-boundary algorithm in `src/scales.rs` is adapted from
`d3-scale` 4.0.2 (`src/linear.js`) and `d3-array` 3.2.5
(`tickSpec` / `tickIncrement`, distributed `dist/d3-array.js`). Independent
fixtures are generated by `scripts/linear-nice-reference.mjs`. These reference
JavaScript packages are development tools; chart code runs in Rust.

## D3 color spaces and named ramps

`src/color_scale/interpolation.rs` follows the color transforms from
`d3-color` 3.1.0 and the interpolators from `d3-interpolate` 3.0.1.
`src/color_scale/schemes.rs` uses the ramp definitions and packed tables
from `d3-scale-chromatic` 3.1.0, including the ColorBrewer palettes. The
adjacent license files reproduce the original ISC and ColorBrewer notices.
The bounded trigonometric kernel in `schemes/trig.rs` retains its original
Sun Microsystems notice. The Rust implementation has no JavaScript runtime
dependency. The independent fixture generators are
`scripts/color-interpolation-reference.mjs` and
`scripts/color-schemes-reference.mjs`.

`src/ordinal_color.rs` also includes the Nivo categorical palette and the ten
D3 categorical palettes named in Nivo's color catalog. The ordinal fixture
uses the original catalog and `d3-scale` 4.0.2. Inherited RGB modifiers follow
Nivo's inherited color configuration and `d3-color` 3.1.0. The Nivo MIT
terms and D3 license notices apply to these references.

## Authored static typography fixtures

The Regular and Bold typography fixtures contain original geometric A/B test
shapes, Hebrew and combining marks, and vertical alternates, under Apache-2.0.
They are test artwork rather than a complete text typeface. FontTools 4.67.0
builds their static OS/2 weights 400/700, independent advances and ink bounds.
[Fixture license](../tests/fonts/KartisFixtureTypography-LICENSE.txt) · [Generator](../scripts/typography-font-reference.py) · [Recorded tables](../tests/fixtures/typography-font-reference.json)

Static weight selection follows the three search orders in
[CSS Fonts Module Level 4, font matching](https://www.w3.org/TR/css-fonts-4/#font-style-matching).
It does not implement synthetic bolding, variable axes or system font lookup.

source for its complete attribution.

## D3 padded pie arcs

`src/pie_layout/pie_arc.rs` adapts the padding, intersection and corner tangent
branches of `d3-shape` 3.2.0 `src/arc.js`; pie angle allocation follows its
`src/pie.js`. Copyright 2010-2022 Mike Bostock, ISC permission and warranty
notice reproduced above. Circular commands are lowered to bounded cubic
segments shared by SVG, Canvas and CPU; this is not a claim of bitwise identity
with SVG elliptical-arc commands. See `scripts/pie-layout-reference.mjs` for
the actual source hashes and independent frozen reference generation.

development-only references, not Rust or chart runtime dependencies.
