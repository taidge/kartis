World country GeoJSON
--------------------
This showcase includes the 176-feature world_countries.json used by Nivo.

Source file: website/src/data/components/geo/world_countries.json

The geographic data is embedded unchanged; country values shown by this showcase are synthetic examples assigned by stable country ID. Borders and names are retained from the upstream dataset and do not express a position on territorial status.

Explicit input adaptation and rendered scope:
The original KOR polygon 0 / ring 0 is not closed. A derived GeoJSON retains all 62 original ring coordinates and appends its first coordinate; all 176 source features remain present. Its SHA-256 is f1729812d1b8e7d3bb7f72401511a80a5399819f460f986ebba0252477547675.
The two gallery maps display the 175 non-Antarctic regions. ATA (Antarctica) is explicitly excluded because the current planar projection profile rejects pole-enclosing spherical-cap topology. No other region is omitted; the library's strict parser, geometry and budget checks remain enabled. The author-data panel records this scope.
