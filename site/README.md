# Kartis chart explorer

[中文](README.zh-CN.md)

A static Rust/WebAssembly showcase for `kartis.taidge.org`. The searchable catalog
contains **35 actual chart types** across Cartesian, part-to-whole, hierarchy,
network, geography and specialized layouts. Every thumbnail is generated by the
same Rust catalog used by the selected interactive chart. The page does not use
chart screenshots, React, remote datasets, external fonts or an analytics service.

The home page pairs a live Line demo with a searchable chart index and a gallery
that can be filtered by family. On smaller screens the index opens from the menu.
Selecting a type opens a full-width plot with a settings section below it. Use
**Chart settings** and **Back to chart** to move between them. The
playground includes SVG/Canvas, Shuffle, automatic demo play/pause, motion presets,
light/dark theme, SVG download, real author-input JSON and a core Rust call excerpt.
Choose a layout preset, then adjust the chart's individual properties and
**Plot margins** (50–150%) on the same dataset. For example, a Waffle chart lets
you change cell spacing and grid dimensions while keeping its chosen fill
direction. A Sankey chart lets you compare node spacing and link opacity at a
fixed node width. A map retains its projection when you adjust the graticule or
symbol radii. The Code tab shows the core Rust call and the selected overrides.

The property panel groups the controls by purpose. On charts with axes, you can change the supported axes and grids independently. For example, Line can show vertical grid lines while hiding the X axis. All chart types offer color schemes and featured datum labels. Charts with owned data labels can hide them independently of tick text. Categorical charts offer Tableau 10 and Dark 2, and continuous-color examples offer Viridis and Magma.

Hover a mark to compare the detailed tooltip with its value alone, change the number format, or hide the tooltip. In both SVG and Canvas, a separate outline follows the active mark even with the tooltip hidden. Moving the pointer over a settled chart preserves the underlying plot. Charts with native legend items can arrange them inline, stack them, or hide the legend. Changing the legend arrangement preserves which series you have hidden.

Configuration and data changes keep the current plot mounted. SVG updates changed attributes on retained marks and preserves stationary ticks when other labels are removed. Canvas restores the old and new painted regions, including overlapping marks or text in drawing order. It uses a full frame for changes to the backing size or background, and for dense overlaps that require a wider repaint. Changing spring settings preserves the positions and velocities of tracks already in motion.

## Build

Requirements: Python 3, Rust 1.95 or later with the `wasm32-unknown-unknown` target,
and `wasm-bindgen-cli` **0.2.130**, matching the locked dependency. From the
repository root:

```sh
python3 site/build.py
python3 -m http.server 8080 --directory site/dist
```

Open `http://localhost:8080`. Deploy **`site/dist`**. The build runs
`cargo metadata` in the independent `site/wasm` workspace and uses its actual
`target_directory`, then a locked release build and wasm-bindgen. It does not
redirect Cargo home, target, temporary paths or global caches. Its own
`site/wasm/Cargo.lock` is checked in. `--toolchain 1.95.0` can select an existing
rustup toolchain. For a fresh builder with rustup, opt into normal tool installation:

```sh
python3 site/build.py --install-tools
```

The public `build.json` includes asset hashes, a content-derived `asset_revision`,
and an optional Git source commit;
it includes no machine paths. Without Git metadata, the commit field is null.
Source archives and deployed assets remain usable without a Git checkout.

## Cloudflare Pages

Use the repository root, build command **`bash site/cloudflare-build.sh`**, and
output directory **`site/dist`**. The wrapper locates `$HOME/.cargo/env`; if rustup
is missing it installs minimal Rust 1.95.0 through the official HTTPS installer.
It then installs the WASM target and matching binding generator in their normal
user locations. It changes tool lookup through PATH, not HOME, CARGO_HOME, target
or temporary directories. A provisioned CI runner can use `python3 site/build.py`.

No site tokens, bindings, API server or environment secrets are required. Pages
Git deployment and custom-domain registration are separate. Serve `.wasm` as
`application/wasm`. `_headers` uses `no-transform` to prohibit edge analytics
injection. Runtime JavaScript, CSS, WASM and binding snippets are published together
under `assets/<asset_revision>/`; HTML entry URLs use that same revision. The
revision hashes all actual runtime file paths and bytes, so even a provider that
extends cache lifetimes cannot mix new JavaScript with an older WASM module.
Each build first cleans only the verified generated `site/dist` directory. Third-party map data attribution is shipped with the site.

## Real motion and lifecycle

Changing a property, layout preset or margin updates the mounted
`BrowserChart` with the current dataset. **Shuffle** keeps the selected settings
when it generates the next dataset. Try changing a property during a data
transition, then shuffling again before the spring settles. Rust drives
`animate_to` on animation frames, matches marks by stable ID, and moves from
the visible frame toward the latest configuration and dataset. Paths with
incompatible topology can crossfade.

Choose Default, Gentle, Wobbly, Stiff, Slow or Molasses, or adjust stiffness and
damping independently. **Replay fade-in** brings the current chart's marks back
from zero opacity using the selected spring. **Pause demo** stops automatic data
changes and lets the current transition finish. With the system's reduced-motion
preference enabled, the demo starts paused, layout and data changes take effect
immediately, and fade-in replay is disabled.

Switching between SVG and Canvas mounts the chosen renderer with the current
dataset. Theme and motion controls update the existing chart. Turning animation
off during a transition takes the chart directly to its target. Resizing uses
the Rust layout callback.

Page hiding disposes the owner and pauses data/status timers. BFCache restoration
uses the retained per-chart author seed; repeated pagehide calls always clean up.
The application does not deep-freeze an input object or simulate a server feed.
Downloading SVG exports the responsive author target, without transient selection
or hidden-legend presentation. Geography uses the bundled, attributed 176-feature world source, with an explicit
175-feature non-Antarctic rendering subset. Antarctica is excluded because this
planar sample does not support its polar-cap geometry; source data, normalization
and exclusion are disclosed in the Data panel. The map is illustrative, not a
geographic boundary authority.

## Verify

From the repository root, using the existing Playwright dependency:

```sh
npm ci
npx playwright install chromium firefox
node site/smoke.mjs
node site/explorer-acceptance.mjs
node site/partial-frame-acceptance.mjs
node site/cache-acceptance.mjs
```

The scripts serve `site/dist` and write JSON, screenshots and exported SVGs under
ignored `site/verification`. `--url=https://example.com` checks a deployment;
`--out=<directory>` changes the evidence directory. They do not deploy or change
an external service. Remote mode checks actual `no-transform` HTTP headers;
analytics injection, analytics requests, console errors and failed requests are
failures, including aborted beacon requests.

The smoke covers real previews, the initial Spring demo, the original six-family
SVG/Canvas interactions, tooltip/legend/download and repeated lifecycle cleanup.
The explorer check exercises the broader catalog, options and motion. The partial-frame
check compares fractional-DPR animation and text against independently rendered Canvas pixels.
The cache regression retains legacy runtime files in a real browser cache and
checks that the new page loads its complete versioned module graph.
Deterministic lifecycle-handler coverage is explicitly separate from trusted
BFCache events when a browser actually retains the page. The reusable Showcase
CI workflow builds the same static output and runs these checks. Passing these
selected scenarios is not a compatibility or performance claim for every API.
