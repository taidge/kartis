# Kartis chart explorer

[中文](README.zh-CN.md)

A static Rust/WebAssembly showcase for `kartis.taidge.org`. The searchable catalog
contains **35 actual chart types** across Cartesian, part-to-whole, hierarchy,
network, geography and specialized layouts. Every thumbnail is generated by the
same Rust catalog used by the selected interactive chart. The page does not use
chart screenshots, React, remote datasets, external fonts or an analytics service.

The first screen contains a live Line demo. Selecting a type opens a larger
playground with SVG/Canvas, Shuffle, automatic demo play/pause, motion presets,
light/dark theme, SVG download, real author-input JSON and a core Rust call excerpt.
Line curves, Bar grouping/orientation, Pie inner radius and Tree orientation are
real layout options. The code panel is a core call, not a complete application.
The source links include the remaining setup and supported options.

## Build

Requirements: Python 3, Rust 1.95 or later with the `wasm32-unknown-unknown` target,
and `wasm-bindgen-cli` **0.2.130**, matching the locked dependency. From the
repository root:

```sh
python3 site/build.py
python3 -m http.server 8080 --directory site/dist
```

Open `http://localhost:8080`. Deploy **`site/dist`**. The build runs
`cargo metadata` in the independent `site/wasm` workspace and uses its actual
`target_directory`, then a locked release build and wasm-bindgen. It does not
redirect Cargo home, target, temporary paths or global caches. Its own
`site/wasm/Cargo.lock` is checked in. `--toolchain 1.95.0` can select an existing
rustup toolchain. For a fresh builder with rustup, opt into normal tool installation:

```sh
python3 site/build.py --install-tools
```

The public `build.json` includes asset hashes and an optional Git source commit;
it includes no machine paths. Without Git metadata, the commit field is null.
Source archives and deployed assets remain usable without a Git checkout.

## Cloudflare Pages

Use the repository root, build command **`bash site/cloudflare-build.sh`**, and
output directory **`site/dist`**. The wrapper locates `$HOME/.cargo/env`; if rustup
is missing it installs minimal Rust 1.95.0 through the official HTTPS installer.
It then installs the WASM target and matching binding generator in their normal
user locations. It changes tool lookup through PATH, not HOME, CARGO_HOME, target
or temporary directories. A provisioned CI runner can use `python3 site/build.py`.

No site tokens, bindings, API server or environment secrets are required. Pages
Git deployment and custom-domain registration are separate. Serve `.wasm` as
`application/wasm`. `_headers` uses `no-transform` to prohibit edge analytics
injection, and revalidation for fixed-name JavaScript/WASM so deployments do not
mix cached versions. Third-party map data attribution is shipped with the site.

## Real motion and lifecycle

One `BrowserChart` owns the live scene. `animate_to` uses Kartis property springs
and its Rust RAF scheduler; plot paths have no CSS transition. Presets configure
real stiffness/damping, and retargets retain physical velocity. Stable mark IDs
connect datasets. Incompatible path topology can crossfade; this is not a claim
that every primitive, time integration or Nivo/React transition is equivalent.

Animation respects the system's reduced-motion preference. The initial automatic
demo is disabled under reduced motion. **Pause demo stops future dataset changes;
the current spring finishes naturally.** Animation off remounts with reduced
motion and applies immediate data updates. Switching renderer, theme, variant or
spring preset also remounts at the current author dataset and resets transient
hover/selection. Resizing uses a real responsive Rust layout callback.

Page hiding disposes the owner and pauses data/status timers. BFCache restoration
uses the retained per-chart author seed; repeated pagehide calls always clean up.
The application does not deep-freeze an input object or simulate a server feed.
Downloading SVG exports the responsive author target, without transient selection
or hidden-legend presentation. Geography uses the bundled, attributed 176-feature world source, with an explicit
175-feature non-Antarctic rendering subset. Antarctica is excluded because this
planar sample does not support its polar-cap geometry; source data, normalization
and exclusion are disclosed in the Data panel. The map is illustrative, not a
geographic boundary authority.

## Verify

From the repository root, using the existing Playwright dependency:

```sh
npm ci
npx playwright install chromium
node site/smoke.mjs
node site/explorer-acceptance.mjs
```

The scripts serve `site/dist` and write JSON, screenshots and exported SVGs under
ignored `site/verification`. `--url=https://example.com` checks a deployment;
`--out=<directory>` changes the evidence directory. They do not deploy or change
an external service. Remote mode checks actual `no-transform` HTTP headers;
analytics injection, analytics requests, console errors and failed requests are
failures, including aborted beacon requests.

The smoke covers real previews, the initial Spring demo, the original six-family
SVG/Canvas interactions, tooltip/legend/download and repeated lifecycle cleanup.
The separate explorer check exercises the broader catalog, options and motion.
Deterministic lifecycle-handler coverage is explicitly separate from trusted
BFCache events when a browser actually retains the page. The reusable Showcase
CI workflow builds the same static output and runs both scripts. Passing these
selected scenarios is not a compatibility or performance claim for every API.
